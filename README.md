# Job Portal Analytics Dashboard

Developed an interactive Job Portal Analytics Dashboard to analyze hiring trends, job market demand, and skill requirements across various industries. The project involved data preprocessing, transformation, and visualization to generate actionable insights from job listing datasets.

### Key Features

* Cleaned and transformed raw job market data for analysis.
* Built interactive Tableau dashboards to visualize hiring patterns.
* Analyzed job roles, companies, locations, and required skills.
* Enabled dynamic filtering for enhanced data exploration.
* Identified trending technologies and in-demand skill sets.

### Tech Stack

* Tableau
* Data Cleaning & Preprocessing
* Excel / CSV Datasets
* Netlify (Deployment)

### Outcomes

* Provided data-driven insights into current recruitment trends.
* Improved understanding of market demand for technical and non-technical roles.
* Created an intuitive dashboard for exploring large-scale job data efficiently.

### Deployment

The dashboard is deployed on Netlify and available for demonstration between **3:00 PM and 5:00 PM**.
